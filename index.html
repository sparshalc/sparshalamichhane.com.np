I'm Sparsha, a full-stack developer in Kathmandu who mostly writes Ruby. To me, full-stack means the whole request: the route, the query, the partial, and the small Stimulus controller that makes it feel instant.

I started out as a graphic designer in 2020 and found Rails in 2022. I learn by building, so that has meant a long tail of Rails apps (blogs, chat rooms, clones of apps everyone uses) and one shop that switches on a real light whenever an order comes in.

Along the way I started reading other people's code and sending fixes back. Today I'm a Mid-level Software Developer at Danphe Software Labs, working on multi-tenant SaaS and Rails engines, and I build small tools for developers on the side.

Off the clock: music, games, and graphic design.

  1. 2020

    :start_with_design

    Graphic designer at MomoChulo and MomoMania in Kathmandu, and later a few months editing video at Sastodeal. Design came first, and it never really left.

  2. 2022

    :find_rails

    Opened a GitHub account in October 2022 and started building with Ruby on Rails.

  3. 2023–26

    :study_computing

    BSc (Hons) Computing at Herald College Kathmandu, after +2 in Physical Sciences at Orchid College.

  4. 2023–now

    :join_danphe

    Joined Danphe Software Labs as an intern in February 2023 and became a Mid-level Software Developer that September. Since then: a multi-tenant architecture for an enterprise SaaS move, a production Employment Management System turned into a reusable Rails engine, and RESTful APIs and third-party integrations.

  5. 2023

    :ship_side_projects

    A long run of Rails apps: WordSmith, a Threads clone, a Turbo chat room, a LinkedIn-style network, Pinfinity, a Chrome extension, and GlowCart, a shop wired to an Arduino.

  6. 2023–24

    :fix_other_peoples_code

    Merged pull requests into good_job, The Odin Project and Ruby for Good's Homeward Tails, mostly UI polish and quality-of-life features.

  7. 2025–now

    :build_tools_for_developers

    A drag-and-drop page builder, a multi-tenant activity tracker, and Claude Control Center, a macOS cockpit for Claude Code written in Swift and shipped through my own Homebrew tap. Picked up a Claude Code 101 certificate along the way.
